## About

This repository contains the frontend of a modern full-stack web application built with React.js and Tailwind CSS. It focuses on delivering a clean, responsive, and user-friendly interface while integrating seamlessly with a RESTful backend API.

# MediCare Frontend

This repository contains the frontend of the **MediCare Doctor Appointment System**. It is built using **React.js**, **Vite**, and **Tailwind CSS**, providing a responsive and user-friendly interface for patients, doctors, and administrators.

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Axios
- React Router DOM

## Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/medicare-frontend.git
```

### Navigate to the project

```bash
cd medicare-frontend
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
VITE_API_URL=http://localhost:5000
```

### Start the development server

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```
